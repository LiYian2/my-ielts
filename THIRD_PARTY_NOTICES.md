# Third-party notices

## British IPA data

This repository includes only the IPA strings matched for the Space Exploration vocabulary cards. They were matched from the Received Pronunciation dataset in [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict), using upstream commit [`43c3570eb3553bdd19fccd2bd0091534889af023`](https://github.com/open-dict-data/ipa-dict/tree/43c3570eb3553bdd19fccd2bd0091534889af023) and `data/en_UK.txt` (Git blob `f33a9d08cba10e434e20b0a6d417857e11680030`). The upstream project is licensed under GPL-3.0; see its [licence](https://github.com/open-dict-data/ipa-dict/blob/43c3570eb3553bdd19fccd2bd0091534889af023/LICENSE).

The four source headwords not present in that pinned file — `envelope`, `compound`, `antenna`, and `fragment` — use explicitly reviewed manual Received Pronunciation fallbacks: `/ˈenvələʊp/`, `/ˈkɒmpaʊnd/`, `/ænˈtenə/`, and `/ˈfræɡmənt/` respectively. No complete upstream dataset is copied into this repository.
